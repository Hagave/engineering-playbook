- An isolation or allowlist check over a config format (compose, k8s, CI) must enumerate every field of that format that reaches outside resources, with one test each, not only the field with the obvious name: compose reaches host data via `type: bind`, `driver_opts.device` on a named volume, and `volumes_from: container:`.
- Commits, PR descriptions, docs and file names never name the project a measurement or session came from, nor a third-party tool the maintainers use: a session folder under `~/.claude/projects/` carries the project's path, and copying it as a label leaked a private project name into a commit message. Say "a pilot project" / "a third-party filter". Safe mentions: this repo, license-required attribution (gitleaks), libraries a skill recommends.
- Replacing a gate's whole-line text pattern with a per-command (tokenized) check drops what the pattern matched by accident: the command run as an argument (`find -exec`, `xargs`, `watch`, `flock`), inside a shell's `-c` script, as `eval`'s arguments, and as a string inside an interpreter one-liner (`python3 -c "os.system(...)"`). Before deleting the pattern, add a corpus row for each of those forms, in every gate that used it (code-write, secret, and the git readers: push attribution, push secrets, review, commit), in `tests/unit/test_gate_evasion.py` / `tests/unit/test_secret_scan.py`.
- A new handler that takes over an existing command or entry point (a mod intercepting a skill's slash command) must keep every entry the old one offered reachable: list them from the old handler (the skill's menu screens) before writing the new one, with one test per entry.
- A pane a mod opens says in its own text what it is and how to drive it (keys, how to leave), puts its exit control first with a hotkey, sets `autoFocus`, and is tried live in a session before its PR: `claude plugin test` presses buttons without focus, so it cannot catch a panel the keyboard never reaches.
- An installer that renders values into a target project's files writes nothing machine-specific into a file that project commits (an absolute home path carries the user name and breaks for teammates): write `$HOME/...` or a discovered path, with a test that the rendered file holds no home path.
- A gate change that reads more input (script files, heredocs, a broader pattern) is replayed through the old and new checks over the recorded Bash commands in `~/.claude/projects/*/*.jsonl` before its PR, and the PR states the verdict changes: reading tracked build scripts blocked 184 of 6900 real commands.
